Master Stokis/Grosir digunakan untuk kulakan salesman dan cek stok di lapangan (Mobile SFA). Data disinkronkan ke aplikasi mobile via md_stokis. Input & perubahan data hanya via Upload Data — gunakan Download Data untuk ekspor CSV, edit di Excel, lalu upload kembali. File Excel wajib memuat kolom Outlet ID sebagai identitas. Saat upload: Outlet ID yang ada di file akan berstatus Active; stokis lama yang tidak ada di file otomatis menjadi Inactive.
