In order to use this application comfortly, you can do the following suggestions:

  • Please use the monitor with the minimal resolution 1280 x 768 (You can set it via Control Panel > Display > Settings).
  • Please use Firefox Mozilla, Google Chrome latest version browsers. Some features will run better at Firefox Mozilla, Google Chrome latest version.
  • Please make sure that javascript on your browser is still active. By default, the Javascript on browsers is active.
