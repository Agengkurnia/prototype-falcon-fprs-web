# 🧪 Skenario Uji Detail: 002. Product (SFA Mobile)

Dokumen ini menjelaskan langkah-langkah pengujian fungsional terperinci, asersi UI, validasi alur transisi state, dan verifikasi data localStorage untuk modul **Katalog Produk & Penyesuaian Stok Kulakan** SFA Mobile.

---

## 📋 Detail Modul

* **File Target**:
  * `Views/Mobile/product_catalog.html` — Daftar Produk & Kontrol Alur Kulakan
  * `Views/Mobile/product_detail.html` — Detail Spesifik Produk
  * `Views/Mobile/restock_review.html` — Review Akhir & Submit Kulakan
* **Penyedia Data**: `wwwroot/js/sfa-store.js` (`SfaStore` — LocalStorage)
* **Pustaka Pendukung**: `Bootstrap 5`, `jQuery 3.7.1`, `SweetAlert2`
* **Total Test Case**: 44 TC
* **Versi Dokumen**: 2.0 (diperluas ke CRUD penuh)

---

## 🛠️ Persiapan & Prasyarat Sistem

1. Reset state produk: jalankan di console browser:
   ```javascript
   localStorage.removeItem('restock_state');
   localStorage.removeItem('temp_restock_adjustments');
   localStorage.removeItem('temp_restock_receipt');
   localStorage.removeItem('temp_restock_grosir');
   localStorage.removeItem('temp_restock_time');
   ```
2. Login sebagai `AGENG.SUGIANTO` / `canvasser`, buka `product_catalog.html`.
3. Pastikan seed data sudah ada (`sfa_seeded_v8_today` terisi di localStorage).

## 🔑 Ringkasan State Machine Modul

```
idle
  └─[Check-in GPS]──► checked_in
        └─[Foto Nota: Ambil Foto]──► restocking
              ├─[Sesuaikan produk]──► (update temp_restock_adjustments)
              ├─[Batal]──► idle (hapus semua temp)
              └─[Tinjau → Submit]──► idle (hapus temp, update stok, catat history)
```

## 🔑 Key localStorage yang Relevan

| Key | Nilai Saat State | Dihapus Saat |
|---|---|---|
| `restock_state` | `"checked_in"` / `"restocking"` | Submit atau Batal |
| `temp_restock_adjustments` | `{[kode]: {name,karton,box,pcs}}` | Submit atau Batal |
| `temp_restock_receipt` | `"nota_belanja_stokis.jpg"` | Submit atau Batal |
| `temp_restock_grosir` | `"Grosir Sinar Jaya"` | Submit atau Batal |
| `temp_restock_time` | ISO timestamp check-in | Submit atau Batal |
| `restock_history` | Array log mutasi stok | Tidak dihapus (akumulatif) |
