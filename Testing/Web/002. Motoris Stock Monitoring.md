## 📝 Kasus Uji

### Blok A — Akses & muat halaman

#### **TC-MS-001: Login dan buka halaman dashboard**
* **Tipe:** Smoke / Akses
* **Langkah:**
  1. Login sesuai bagian [Akses & Login](#-akses--login).
  2. Buka URL dashboard Motoris Stock.
* **Hasil yang diharapkan:**
  - Judul: **Motoris Stock Monitoring**
  - Subtitle: *Dashboard / Motoris Stock — stock, visit, and motoris sales monitoring (read-only)*
  - Tombol **Export Excel** dan **Refresh** terlihat
  - Label **Updated …** (bukan "Loading…") muncul setelah data selesai dimuat

#### **TC-MS-002: Muat awal tanpa error API**
* **Tipe:** Fungsional / Integrasi
* **Langkah:**
  1. Buka halaman dengan F12 → tab **Network** aktif.
  2. Filter request: `GtStockMotoris`.
  3. Tunggu hingga semua request selesai.
* **Hasil yang diharapkan:**
  - `GetFilters` → HTTP 200
  - `GetDashboard` → HTTP 200
  - `GetChartPergerakanWilayah`, `GetChartTop10Motoris`, `GetChartTrenHarian`, `GetChartKontribusiUmbrand` → HTTP 200
  - `GetBalance`, `GetHistory` → HTTP 200
  - Tidak ada alert error SweetAlert dari `MasterDataApi.notifyError`
  - Konsol bebas error merah (Chart.js / DataTables)

#### **TC-MS-003: Default filter tanggal**
* **Tipe:** UI
* **Langkah:**
  1. Buka halaman (hard refresh: Ctrl+F5).
  2. Periksa `#filterDateStart` dan `#filterDateEnd`.
* **Hasil yang diharapkan:**
  - Start Date = **29 hari sebelum** End Date (total 30 hari inklusif)
  - End Date = **hari ini** (sesuai tanggal sistem)

---

### Blok B — Filter & chips

#### **TC-MS-010: Dropdown Region (provinsi)**
* **Tipe:** Fungsional
* **Langkah:**
  1. Klik dropdown **Region**.
  2. Periksa daftar opsi.
* **Hasil yang diharapkan:**
  - Opsi pertama: **All Indonesia (National)**
  - Hanya nama **provinsi** (11 provinsi load test), **tanpa** `Region 1`, `Region 2`, dll.
  - Contoh: `Jawa Barat`, `Sumatera Utara`, `DKI Jakarta`, `Kalimantan Barat`, …

#### **TC-MS-011: Cascade Region → Area**
* **Tipe:** Fungsional
* **Langkah:**
  1. Pilih Region: **Kalimantan Barat**.
  2. Tunggu reload.
  3. Buka dropdown **Area**.
* **Hasil yang diharapkan:**
  - Area hanya menampilkan kota di Kalimantan Barat (mis. Ketapang, Pontianak, Singkawang, Sambas)
  - KPI dan chart ter-update (angka lebih kecil dari nasional)
  - Chip filter muncul: ikon globe + nama provinsi

#### **TC-MS-012: Filter Motoris tunggal**
* **Tipe:** Fungsional
* **Langkah:**
  1. Set Region + Area (mis. Kalimantan Barat / Ketapang).
  2. Pilih satu nama di dropdown **Motoris**.
* **Hasil yang diharapkan:**
  - **Active Motoris Fleet** = **1**
  - Balance grid & audit trail hanya untuk motoris tersebut
  - Chip filter motoris muncul

#### **TC-MS-013: Filter Umbrella Brand**
* **Tipe:** Fungsional
* **Langkah:**
  1. Pilih satu **Umbrella Brand** dari dropdown.
  2. Amati chart kontribusi umbrand & KPI faktur.
* **Hasil yang diharapkan:**
  - Donut chart men-highlight brand terpilih (slice lain transparan)
  - Chip **Brand: …** muncul
  - Sales Invoices (jika ada data brand tersebut) terfilter

#### **TC-MS-014: Ubah rentang tanggal**
* **Tipe:** Fungsional
* **Langkah:**
  1. Set **Start Date** = `2026-01-01`, **End Date** = `2026-12-31`.
  2. Tunggu reload.
  3. Catat **Sales Invoices** KPI.
  4. Kembalikan ke default 30 hari.
* **Hasil yang diharapkan:**
  - KPI faktur **naik signifikan** pada rentang full year (load test ~2,8 juta faktur nasional)
  - Chart trend harian menampilkan lebih banyak titik
  - Request `GetDashboard` pada full year: catat waktu respons (catatan performa)

#### **TC-MS-015: Filter chips & reset**
* **Tipe:** UX
* **Langkah:**
  1. Aktifkan beberapa filter (Region, Area, Brand).
  2. Klik **×** pada satu chip.
  3. Klik link **Reset All** (jika tampil).
* **Hasil yang diharapkan:**
  - Menghapus chip menghapus filter terkait dan me-reload data
  - Reset All mengosongkan semua filter & mengembalikan tanggal default 30 hari

### Blok C — KPI cards (5 kartu)

#### **TC-MS-020: Active Motoris Fleet**
* **Filter:** Kalimantan Barat → Ketapang
* **Hasil yang diharapkan:** Angka > 0 (beberapa motoris di area tersebut); konsisten setelah refresh

#### **TC-MS-021: Customers**
* **Hasil yang diharapkan:** Jumlah pelanggan terdaftar untuk motoris dalam scope filter (`mGtPelanggan` per `intSalesmanID`)

#### **TC-MS-022: Sales Invoices**
* **Hasil yang diharapkan:** Jumlah `trGtFaktur` dalam rentang tanggal & scope geo; > 0 untuk area dengan data load test

#### **TC-MS-023: Visits**
* **Hasil yang diharapkan (saat ini):** **0** — documented limitation; subtitle "made in selected period"
* **Catatan tester:** Jangan laporkan sebagai bug data inject; laporkan sebagai **fitur backend belum aktif** jika stakeholder mengharapkan angka > 0

#### **TC-MS-024: Effective Visits (Effective Call)**
* **Hasil yang diharapkan (saat ini):** **0%**; subtitle format `X of 0 visits transacted` (X = jumlah faktur)
* **Catatan:** Sama seperti TC-MS-023

### Blok D — Stock Movement Flow

#### **TC-MS-030: Tiga node alur stok**
* **Langkah:** Perhatikan kartu *Stock Movement Flow Visualization*
* **Hasil yang diharapkan:**
  | Node | Elemen | Sumber |
  |------|--------|--------|
  | Stokis / Official Wholesaler | `#flowStokis` | Inbound history (filter tanggal) |
  | Motoris (Sales) | `#flowMotoris` | Saldo stok (`trGtStockMotoris`) |
  | Grocery Outlet | `#flowOutlet` | Outbound history (filter tanggal) |
  - Ketiga nilai format singkat Rp (mis. `Rp 1.7 B`), **bukan** placeholder abu-abu
  - Dengan filter Ketapang + 30 hari: **Inbound (Stokis) > 0** setelah perbaikan data inbound bulanan

### Blok E — Charts & Analytics

#### **TC-MS-040: Section collapse**
* **Langkah:** Klik header **Charts & Analytics** untuk collapse/expand
* **Hasil yang diharapkan:** Konten chart tersembunyi / tampil; ikon chevron berputar

#### **TC-MS-041: National / Regional Stock Movement (bar chart)**
* **Langkah:**
  1. Tanpa filter provinsi: chart menampilkan level **provinsi**.
  2. Klik salah satu bar provinsi.
* **Hasil yang diharapkan:**
  - Drill-down ke level **kota** (judul berubah, tombol **Back to Regions** muncul)
  - Bar menampilkan **Inbound** vs **Outbound** (dua warna/seri)
  3. Klik **Back to Regions** → kembali ke level provinsi

#### **TC-MS-042: Top 10 Motoris (Sell-Through)**
* **Filter:** Area dengan data outbound + inbound dalam rentang tanggal
* **Hasil yang diharapkan:**
  - Horizontal bar chart dengan nama motoris di sumbu Y
  - Nilai sell-through ~**75%** (hijau/oranye/merah berdasarkan threshold 70% / 40%)
  - **Bukan** chart kosong jika inbound & outbound sama-sama ada di rentang tanggal

#### **TC-MS-043: Daily Sales Trend**
* **Hasil yang diharapkan:** Line chart dengan label tanggal (format display date); nilai ≥ 0; garis terisi (area fill)

#### **TC-MS-044: Umbrella Brand Contribution**
* **Langkah:**
  1. Tanpa filter brand: donut + legend + persen di tengah
  2. Klik item legend untuk toggle slice
  3. Pilih brand di filter dropdown
* **Hasil yang diharapkan:** Donut ter-render; legend interaktif; filter brand menonaktifkan label persen di slice (center label menampilkan brand terpilih)

### Blok F — Running Stock Balance per Motoris

#### **TC-MS-050: Grid balance load & pagination**
* **Langkah:** Scroll ke tabel **Running Stock Balance per Motoris**
* **Hasil yang diharapkan:**
  - DataTable server-side: kolom No, Motoris, Region, Purchase Value, Sales Value, Balance Value
  - Pagination berfungsi
  - Empty state: gambar `data_not_found.png` + teks `no data available in table` jika scope kosong

#### **TC-MS-051: Klik nama motoris → popup detail**
* **Langkah:** Klik link nama motoris (hijau/tebal) di kolom Motoris
* **Hasil yang diharapkan:**
  - SweetAlert popup **Motoris detail** dengan header gradient hijau
  - Informasi: NIK, area, provinsi, saldo, tabel SKU, kulakan terakhir, penjualan 7 hari, daftar outlet
  - Popup dapat ditutup

#### **TC-MS-052: Konsistensi nilai balance**
* **Filter:** Satu motoris + rentang tanggal tertentu
* **Hasil yang diharapkan:**
  - **Purchase Value** = agregat Inbound history dalam rentang
  - **Sales Value** = agregat Outbound history dalam rentang
  - **Balance Value** = saldo dari `trGtStockMotoris` (tidak berubah saat ganti tanggal saja)

### Blok G — Stock Movement Audit Trail

#### **TC-MS-060: Grid audit trail**
* **Hasil yang diharapkan:**
  - Kolom: No, Date, Motoris, Type, Product, Value (Rp), Outlet / Stokis
  - Badge **Inbound** (hijau) dan **Outbound** (merah) pada kolom Type
  - Urutan default: tanggal terbaru di atas

#### **TC-MS-061: Ada baris Inbound dan Outbound**
* **Filter:** Kalimantan Barat → Ketapang → 30 hari terakhir
* **Hasil yang diharapkan:**
  - Minimal beberapa baris **Inbound** (kulakan dari stokis) — tidak hanya Outbound
  - Outbound menampilkan nama outlet (pelanggan); Inbound menampilkan nama stokis

#### **TC-MS-062: Detail audit (klik baris / tombol detail)**
* **Langkah:** Klik aksi detail pada satu baris audit (Inbound dan Outbound masing-masing sekali)
* **Hasil yang diharapkan:**
  - Popup audit dengan nomor transaksi, tanggal, motoris, produk, qty, GPS, status Verified/Pending
  - Tombol print (jika GPS valid, peta Leaflet tampil)
  - Data konsisten dengan baris grid

### Blok I — Performa (opsional, data load test)

#### **TC-MS-080: Waktu respons API — scope kecil**
* **Filter:** Satu provinsi + satu kota + 30 hari
* **Hasil yang diharapkan:** `GetDashboard` + chart + grid < **7 detik** (target tim)

#### **TC-MS-081: Waktu respons API — nasional full year**
* **Filter:** All Indonesia + `2026-01-01` s/d `2026-12-31`
* **Langkah:** Catat waktu `GetDashboard` dan load halaman di Network
* **Hasil yang diharapkan:** Dokumentasikan waktu aktual; boleh lebih lambat karena volume ~2,8 juta faktur & jutaan history — gunakan sebagai baseline performa

### Blok J — Negative & edge cases

#### **TC-MS-090: Area tanpa motoris**
* **Langkah:** Pilih kombinasi Region/Area yang valid tapi jarang berisi motoris (jika ada)
* **Hasil yang diharapkan:** KPI = 0; grid empty state; tidak error JS

#### **TC-MS-091: Tanggal invalid (start > end)**
* **Langkah:** Set Start Date **setelah** End Date
* **Hasil yang diharapkan:** Catat perilaku (data kosong atau error API); dokumentasikan untuk tim dev

#### **TC-MS-092: Session expired**
* **Langkah:** Biarkan idle lama atau hapus cookie session, lalu klik Refresh
* **Hasil yang diharapkan:** Redirect ke login atau pesan error terkontrol (bukan blank page)

## 🤖 Otomasi Playwright

Skrip otomatis memetakan sebagian besar TC di atas ke test runner Node.js + Playwright.

### Struktur berkas

```
Testing/Web/automation/motoris-stock/
  config.js              # URL, kredensial, filter default
  auth.js                # Login + simpan session (.auth/maven-dev.json)
  helpers.js             # Helper UI/API
  motoris-stock.test.js  # Runner utama
  results.json           # Output hasil (gitignored)
  screenshots/           # Screenshot akhir (gitignored)
```

### Prasyarat

1. Node.js 18+ dan `npm install` di root **Prototype** (Playwright sudah ada di `package.json`).
2. Install browser Chromium (sekali saja):

```bash
cd Prototype
npx playwright install chromium
```

### Menjalankan

```bash
cd Prototype
npm run test:motoris-stock
```

Mode browser terlihat (debug):

```bash
MAVEN_HEADLESS=false npm run test:motoris-stock
```

Override environment (opsional):

| Variabel | Default |
|----------|---------|
| `MAVEN_BASE_URL` | `https://mavendev.kalbenutritionals.web.id` |
| `MAVEN_USER` | `ageng.sugianto` |

| `MAVEN_CAPTCHA` | `bypass` |

- Konsol: `[PASS]` / `[FAIL]` per TC
- `results.json` — detail JSON untuk CI
- `screenshots/motoris-stock-final.png` — bukti visual
- Exit code `0` = semua pass, `1` = ada failure

Session login disimpan di `.auth/maven-dev.json` agar run berikutnya tidak login ulang (hapus file ini jika session expired).
