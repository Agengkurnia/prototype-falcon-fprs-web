## 📝 Skenario Kasus Uji (Test Cases)

### **TC-001-01: Verifikasi Penyimpanan Status Login (Auth Persistence)**
* **Tujuan**: Memastikan sesi login (cookies & localStorage) berhasil disimpan ke berkas `playwright_state.json` untuk pengujian berulang tanpa login ulang.
* **Langkah Uji**:
  1. Jalankan script Playwright untuk melakukan login pertama kali ke URL `https://app.simplidots.co.id/condensed/login`.
  2. Isi email: `sarahnurainim@gmail.com` and password: `@Kalbe01`.
  3. Klik tombol **Login** dan tunggu hingga halaman dashboard utama termuat.
  4. Panggil method `context.storageState({ path: 'playwright_state.json' })`.
  5. Jalankan script kedua dengan memuat status yang disimpan: `chromium.launch(...)` -> `newContext({ storageState: 'playwright_state.json' })` -> buka direktori dashboard.
* **Hasil yang Diharapkan**:
  * Berkas `playwright_state.json` berhasil terbuat dan tidak berukuran 0 byte.
  * Pada eksekusi script kedua, browser langsung masuk ke dashboard utama tanpa menampilkan halaman login/form isian email.

---

### **TC-001-02: Verifikasi Ekstraksi Data Tabel (DataTables Extraction)**
* **Tujuan**: Memastikan scraper dapat membaca baris, kolom, dan tombol aksi dari tabel dinamis dengan benar.
* **Langkah Uji**:
  1. Buka halaman master data target (contoh: Kategori Produk / Produk).
  2. Jalankan selektor pengecekan jumlah baris: `await page.locator('table.dataTable tbody tr').count()`.
  3. Ambil teks kolom SKU/Kode dan Nama Produk dari baris pertama.
* **Hasil yang Diharapkan**:
  * Jumlah baris terdeteksi > 0.
  * Teks SKU dan Nama Produk tidak kosong atau bernilai `undefined`.

---

### **TC-001-03: Verifikasi Penanganan Input Dropdown (Select2 LOV)**
* **Tujuan**: Memastikan scraper dapat berinteraksi dengan komponen input dropdown pihak ketiga (Select2) untuk pencarian dan pemfilteran data.
* **Langkah Uji**:
  1. Klik elemen kontainer Select2 untuk memunculkan input teks pencarian: `await page.click('span.select2-selection')`.
  2. Ketik nama filter pencarian (misal: `"Susu"`) pada kolom input pencarian: `await page.fill('input.select2-search__field', 'Susu')`.
  3. Pilih baris hasil pencarian pertama: `await page.click('ul.select2-results__options >> li:has-text("Susu")')`.
* **Hasil yang Diharapkan**:
  * Dropdown memunculkan pilihan hasil pencarian yang relevan.
  * Nilai terpilih terpasang di elemen form input utama.

---

### **TC-001-04: Verifikasi Skema Data Hasil Ekstraksi (Data Compliance)**
* **Tujuan**: Memastikan struktur berkas JSON hasil scraping sesuai dengan kontrak model data master Falcon FPRS.
* **Langkah Uji**:
  1. Jalankan scraper untuk memproduksi berkas mock JSON data master.
  2. Bandingkan properti kunci JSON output dengan standar properti di `project_overview.md` (misal untuk produk: wajib memiliki property `code`, `name`, `price`, `stock`, `conversionCtn`).
* **Hasil yang Diharapkan**:
  * Berkas JSON tervalidasi sukses tanpa ada properti kunci yang hilang (*missing required properties*).
